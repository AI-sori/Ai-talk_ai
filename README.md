## 📍 프로젝트 개요
비대면 환경에서 수집된 영유아의 비정형 데이터(영상, 음성)를 분석하여 언어 발달 지연을 조기에 진단하는 AI 시스템입니다.
고가의 장비 없이 웹캠과 마이크만으로 신뢰도 높은 언어 발달 상태를 확인하고, 데이터 기반의 맞춤형 진단 리포트를 제공합니다.


## 🛠 데이터 분석 및 진단 파이프라인
### 1. 실시간 시선 추적 (Eye-Tracking) ➡️ 집중도(Concentration) 산출
- **문제 해결**: 웹캠 환경의 조명 및 표정 변화로 인한 기존 모델의 추정 불안정성을 극복하기 위해, MediaPipe Face Mesh 기반의 **68개 랜드마크 보정 회귀 모델** 적용.
- **지표 도출**: 5개 보정 포인트를 활용해 **시선 이동의 일관성을 수치화하고 역행/머무름에 페널티 부여**. (25-30 FPS 실시간 처리)

### 2. 발화 음성 분석 (Speech Analysis) ➡️ 명확성(Clarity) & 유창성(Fluency) 산출
- **명확성(Clarity)**: Google Cloud Speech API의 추정 정확도(Confidence)와 발화 메타데이터를 결합한 자체 알고리즘 적용.
   - 명확성 점수 = (Confidence * 70%) + (문장 길이 보너스 * 20%) + (단어 수 보너스 * 10%)

- **유창성(Fluency)**: 전체 발화 시간 중 무음 구간(Silence) 비율을 분석하여 끊김 없는 말하기 능력을 정량 평가.

### 3. 종합 진단 및 약점 자동 분석 (Leveling Logic)
- **종합 점수**: 3대 지표에 가중치를 부여하여 계산 (집중도 * 33%) + (명확성 * 33%) + (유창성 * 34%).

- **레벨 분류**: Advanced(80점 이상), Intermediate(60점~79점), Beginner(60점 미만) 3단계로 분류하여 직관적인 결과 제공.

- **약점 도출**: 세부 지표 중 최저 점수 항목(min(scores))을 시스템이 자동 탐지하여 최우선 개선 과제로 피드백 산출.


## 🧑‍💻 핵심 기여 (AI/Data 파트 전담)
-  **AI 데이터 분석 파이프라인 구축**: MediaPipe(시선 추적)와 Google Cloud Speech API(음성 분석)를 연동한 실시간 스트리밍 데이터 처리 및 백엔드 구현.

- **자체 진단 평가 지표(Metric) 설계**: API 결과값에 의존하지 않고, 음성 인식 Confidence 및 랜드마크 좌표 등을 결합하여 **정량적 평가 수식 자체 개발**.

- **맞춤형 종합 스코어링 알고리즘 구현**: 3대 세부 지표를 가중 평균하여 발달 레벨을 자동 분류하고 취약점을 도출하는 비즈니스 **로직(서비스화) 설계**.
